# Job Requirements Q&A


### Q1:
**Câu hỏi:** Yêu cầu cho vị trí Software Engineer - Intern?
**Biến thể:**
- Yêu cầu tuyển dụng Software Engineer - Intern là gì?
- Software Engineer - Intern cần những kỹ năng gì?
- Tiêu chí tuyển Software Engineer - Intern
- Job description cho Software Engineer - Intern
**Trả lời:**
Yêu cầu cho vị trí Software Engineer - Intern:
- Kỹ năng bắt buộc: Python Programming, Data Structures, Algorithms, Object-Oriented Programming (OOP) principles, Git Version Control, Command Line Interface (CLI) proficiency, Basic Debugging Techniques, Problem Solving Logic
- Kỹ năng ưu tiên: SQL (SELECT, INSERT, UPDATE, DELETE), HTML5, CSS3, JavaScript (ES6+), RESTful API concepts, Linux/Unix OS familiarity, Unit Testing frameworks (e.g., Pytest, JUnit), Web Framework exposure (e.g., Flask, Django, Node.js Express, Spring Boot, React, Angular, Vue.js), Cloud Computing fundamentals (AWS EC2, S3, Azure VMs, GCP Compute Engine), Agile/Scrum methodology understanding, Docker fundamentals
- Kinh nghiệm: Ít nhất 0 năm
- Học vấn: Bachelor (Các ngành: Computer Science, Software Engineering, Information Technology, Computer Engineering)
- Chứng chỉ: Scrum Master, TOGAF, ITIL
