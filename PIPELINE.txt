│       │                                                                                    │
│       ▼                                                                                    │

│  │                                                                                    │   │
│  │  [20pts] Required Skills  ── keyword match in CV text                             │   │
│  │  [10pts] Preferred Skills ── keyword match in CV text                             │   │
│  │  [15pts] Experience       ── regex extract years of experience                    │   │
│  │  [10pts] Education        ── keyword match (major/university)                     │   │
│  │  [ 5pts] Certifications   ── keyword match (AWS, GCP, etc.)                      │   │
│  │  [40pts] Semantic Match   ── SentenceTransformer cosine similarity                │   │

┌────────────────────────────────────────────────────────────────────────────────────────────┐
│                       RAG PIPELINE (Retrieval-Augmented Generation)                        │
│                                                                                            │
│                                                                                            │
│  HR uploads PDF ──► policies.py router                                                     │
│       │                                                                                    │
│       ├──► PyPDF2 extracts text                                                            │
│       │                                                                                    │
│       ├──► Chunk text (split by \n\n, min 50 chars)                                       │
│       │                                                                                    │
│       ├──► Embed each chunk ──► ChromaDB "hr_policies" collection                         │
│       │         (using Online Gemini Embedding OR Offline e5-large)                       │
│       │                                                                                    │
│       └──► Rebuild BM25 index (HybridRetriever)                                           │
│                                                                                            │
│                                                                                            │
│  Employee asks question ──► Chat endpoint                                                  │
│       │                                                                                    │
│       ▼                                                                                    │
│  ┌──────────────────────────────────────────────────────────────────────┐                  │
│  │                    HybridRetriever.retrieve()                        │                  │
│  │                                                                      │                  │
│  │  Query ──► Vector Search (ChromaDB)  ──────────────────► scores      │                  │
│  │        ──► BM25 Keyword Search       ──────────────────► scores      │                  │
│  │                         │                      │                     │                  │
│  │                         └──── RRF Fusion ──────┘                     │                  │
│  │                                   │                                  │                  │
│  │                         Cross-Encoder Reranker                       │                  │
│  │                     (bge-reranker-v2-m3, optional)                   │                  │
│  │                                   │                                  │                  │
│  │                         Top-K relevant chunks                        │                  │
│  └──────────────────────────────────────────────────────────────────────┘                  │
│       │                                                                                    │
│       ▼                                                                                    │
│  LLM (Gemini / offline_agent) ──► Final Answer (streamed SSE)                             │
└────────────────────────────────────────────────────────────────────────────────────────────┘

║  TECH STACK LEGEND                                                                          ║
║                                                                                             ║
║  Frontend   : Next.js 14, TypeScript, Tailwind CSS                                         ║
║  Backend    : FastAPI (Python 3.14), SQLModel, Alembic (migrations)                        ║
║  Rel. DB    : SQLite  (via data/paraline.db)                                                ║
║  Vector DB  : ChromaDB (persistent, local)                                                  ║
║  LLM Online : Google Gemini 1.5 Flash + Gemini Embedding v2                                ║
║  LLM Offline: intfloat/multilingual-e5-large (SentenceTransformer)                         ║
║  RAG        : HybridRetriever = ChromaDB + BM25 (RRF fusion) + Cross-Encoder rerank        ║
║  OCR        : PyMuPDF (fitz) → pdfplumber → EasyOCR (fallback chain)                       ║
║  AI Orch.   : LangChain + LangGraph (multi-agent state machine)                            ║
║  Auth       : JWT (HS256) via python-jose + passlib (pbkdf2-sha256)                        ║
